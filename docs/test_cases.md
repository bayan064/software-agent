1. 两数之和 (Two Sum) - Easy
题目需求: 在给定数组 nums 中找到两个数，使其和等于目标值 target。返回这两个数的下标。

输入示例: nums = [2, 7, 11, 15], target = 9

预期输出: [0, 1]

2. 回文数 (Palindrome Number) - Easy
题目需求: 判断一个整数 x 是否为回文数（正读反读都一样）。

输入示例: x = 121 -> true；x = -121 -> false

预期输出: 布尔值

3. 反转字符串 (Reverse String) - Easy
题目需求: 编写一个函数，原地（in-place）反转字符数组 s。

输入示例: s = ["h","e","l","l","o"]

预期输出: ["o","l","l","e","h"]

4. 字符串转换整数 (atoi) - Medium
题目需求: 实现 myAtoi(string s)，将字符串转为 32 位有符号整数。需处理空格、正负号。

输入示例: s = "   -42"

预期输出: -42

5. 最长回文子串 (Longest Palindromic Substring) - Medium
题目需求: 找出给定字符串 s 中最长的回文子串。

输入示例: s = "babad"

预期输出: "bab" 或 "aba"
